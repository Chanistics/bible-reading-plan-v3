# Bible Reading Plan V3

개역한글 본문과 KJV 1769, 히브리어와 헬라어 원어 자료를 함께 볼 수 있는 정적 성경 통독 앱입니다.

## 실행

`index.html`을 브라우저에서 직접 열어 사용할 수 있습니다. 유대력 5786~5789의 완전한 통독 주기와 개역한글 본문은 앱에 포함되어 있으므로 첫 실행도 별도 서버 없이 가능합니다. 5790 이후에는 인터넷 연결 시 Hebcal에서 달력 데이터를 받아 같은 방식으로 플랜을 생성합니다. GitHub Pages 정적 사이트로도 배포할 수 있습니다.

## 주요 기능

- 오늘의 통독과 토라 포션 일정
- 주간 파라샤 설명과 탐구 주제, 가로형 7일 읽기 목록
- 파라샤 설명 아래 주간 토라·메길롯·구약·신약 읽기 범위와 한 주 일괄 완료/취소
- 주간 요일별 범위를 눌러 본문 읽기, 절을 선택해 원어 해설 팝업 열기
- 주간 보기에서 지난 날짜를 포함한 요일별 완료·취소 및 달력 상태 연동 (완료 초록, 오늘까지 미완료 빨강, 미래 예정 기본색)
- 실제 기기 날짜 기준 통독표, 진행도·날짜·앱 링크 없이 묵상 내용만 공유 (지원 기기에서 공유 앱 선택, 그 외 복사)
- 개역한글과 KJV 1769 병기
- 절 단위 히브리어와 헬라어 원문
- 원어 단어와 KJV Strong 대응어
- Strong 사전 정보와 Bible Hub 링크

## 데이터

- 개역한글: Korean-Bible-1961-KRV 정적 데이터 (대한성서공회 성경전서 개역한글판 표기 유지)
- KJV 1769 및 신약 원어: KJV1769x/Translator's Textus Receptus 계열 데이터
- 구약 원어: OpenHebrewBible BHSA 8-layer 및 공식 KJV 대응표
- 달력: Hebcal Jewish Calendar API 정적 스냅샷

상세 출처, 라이선스, 재생성 방법은 `tools/sources`와 `tools/build-*.js`에 보존되어 있습니다.

## 검증

`npm test`는 일정 경계와 날짜 연속성, 실제 절기 날짜, 파라샤 알리야 배분, 메길롯 중복, 전체 통독 배분, JavaScript 문법, 66권·1,189장·31,102절 커버리지, 모든 파라샤 의미, 원어 절 커버리지, 사전 의미 무결성, KJV Strong 위치를 검사합니다. 같은 검사는 GitHub Pages 배포 전에 자동 실행됩니다.

`npm run test:weekly`는 네 주기의 1,449일과 207주에 대해 화면에 표시하는 읽기 범위와 요일별 본문 읽기 연결을 실제 배정된 장·절과 대조합니다. 범위를 합칠 때 누락된 절·장을 채우지 않는지, 주 전체 완료·취소가 해당 주와 현재 읽기표 안에서만 적용되는지도 검사합니다.

`npm run test:progress`는 지난 날짜 완료·취소와 기록 저장, 달력 상태 판정, 테스트 날짜 제거, 묵상만 공유하는 내용 구성, 공유 취소·실패 및 로컬 복사 대체 동작을 검사합니다.

### 특별 본문 배정

- 요나서 1–4장은 욤키푸르 당일, 오바댜서 1장은 바이트쉴라흐 토요일에 전권 배정합니다. 두 책의 기존 순차 배정은 제거하며 나머지 장의 날짜는 유지합니다.
- 신명기 33–34장은 마지막 토라 알리야 이후의 쉐미니 아쩨렛·심하트 토라에 한 번 배정합니다. 해당 절기가 다음 읽기표의 시작 주간에 속하면 현재 읽기표의 마지막 토요일에 완독 본문을 배정합니다. 절기 날짜와 표시는 이동하지 않습니다.
- 이전 읽기표의 완료 기록은 읽은 장을 기준으로 옮기고 원본은 기기에 보관합니다. 하나의 구약 항목에 읽은 장과 아직 읽지 않은 장이 함께 있으면 전체 완료로 표시하지 않습니다.
