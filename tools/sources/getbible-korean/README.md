# GetBible Korean source

The bundled Korean text is generated from
`https://api.getbible.net/v2/korean.json`.

GetBible identifies this dataset as Korean Revised Version 1952/1961 from
Wikisource, distribution version 2.0.1, Public Domain, SHA
`ab33d24c8ba9180d727b83eb0570aa60b174af84`.

Rebuild with:

```sh
node tools/build-korean-bible-data.js
```
